1. EXECUTIVE SUMMARY & SYSTEM PURPOSE
====================================================================================================
SKILLUP is a multi-tenant web platform designed to align workforce competency with labor market 
demands. It facilitates real-time collaboration between three key stakeholders:
  1. Job Applicants / Upskilling Candidates: Individuals seeking employment or vocational upskilling.
  2. Employers / Enterprise Recruiters: Companies posting vacancies with specific skill requirements.
  3. PESO Administrators / Employment Officers: Government coordinators who audit employers,
     screen applicants, manage training programs, facilitate referrals, and monitor retention.

Core Value Propositions:
- Skill-Driven Matching: Replaces unstructured keyword search with verified competency ratings (1 to 5).
- Automated Skill Gap Detection: Pinpoints exact missing or deficient skills per applicant per vacancy.
- Integrated Upskilling Loop: Automatically links identified skill gaps to relevant PESO/TESDA training courses.
- Comprehensive Employment Tracking: Monitors the end-to-end recruitment lifecycle from application to 
  onboarding, pre-employment document verification, and 30/60/90-day employment retention.

2. TECHNOLOGY STACK & SYSTEM ARCHITECTURE
====================================================================================================
- Backend Framework: Python / Django Web Framework
- Database Layer: Relational Database (SQLite / PostgreSQL) managed via Django ORM
- User Authentication: Django Auth System extended via custom Profile models & OTP verification
- Frontend Architecture: Semantic HTML5, CSS3, JavaScript (Vanilla ES6+), Chart.js / ApexCharts
- Application Structure:
    * `skillup_project/`: Main Django project configuration, settings, routing, and WSGI/ASGI handlers.
    * `tracker/`: Core application containing models, views, URL routes, forms, templates, and business logic.
    * `tracker/templates/tracker/`: Role-segregated presentation templates (ADMIN, APPLICANT, EMPLOYER).
    * `media/`: Storage for candidate documents, resumes, certifications, pre-employment files, and logos.

3. DATABASE SCHEMA & DATA MODEL OVERVIEW
====================================================================================================
The system is built on normalized relational entities defining users, competencies, vacancies, and referrals:

1. `Profile` (One-to-One with Django `User`):
   - Handles role-based partitioning (`applicant`, `employer`, `admin`).
   - Applicant Fields: title, birthdate, civil_status, experience_years, preferred_job, profile_picture.
   - Employer Fields: company_name, industry, company_size, website, contact_email, company_logo.

2. `CentralizedSkill`:
   - Standardized taxonomy of skills (e.g., Python, Welding SMAW, Customer Service, Revit 3D CAD).
   - Categorized by industry domain (IT, BPO, Engineering, Healthcare, Trade/Vocational, etc.).

3. `ApplicantSkill`:
   - Relates an applicant's `Profile` to a `CentralizedSkill` with a proficiency level (1 to 5) and source (`self` vs `PESO Verified`).

4. `JobVacancy` & `JobSkillRequirement`:
   - Vacancy details: title, employer, category, salary range, slots, remaining_slots, status (Open/Closed).
   - Requirements: Maps required `CentralizedSkill` items with target proficiency thresholds (1 to 5).

5. `TrainingProgram` & `TrainingEnrollment`:
   - Programs: title, provider (e.g., TESDA/PESO), skills addressed, duration, schedule, max slots, remaining slots, status.
   - Enrollments: links applicant profile to training program with status (`Enrolled`, `Attended & Completed`, `No Show`).

6. `Referral` (Central Placement & Compliance Hub):
   - Multi-stage state machine tracking applicant progress through the entire recruitment and onboarding process.
   - Pre-employment uploads: NBI clearance, Medical certificate, SSS, PhilHealth, Pag-IBIG, BIR TIN, Transcript.
   - Post-hiring audit: Start date, reporting status, mid-probation evaluations, and regularization status.

7. `Interview`:
   - Tracks scheduling between applicant and employer (date, time, interview type, meeting link, notes).

8. `Notification`:
   - Real-time in-app alerts for job matches, referral updates, interview invites, and status updates.

9. `GapScoreLog` & `JobBookmark`:
   - Stores algorithmic match percentage snapshots and applicant saved jobs.

5. END-TO-END SYSTEM LIFECYCLE WORKFLOWS
====================================================================================================

----------------------------------------------------------------------------------------------------
5.1. STAGE 1: REGISTRATION, VERIFICATION & ROLE DISPATCH
----------------------------------------------------------------------------------------------------
1. User navigates to `/signup/` and registers by selecting their target role (Applicant, Employer, Admin).
2. The system generates an account record, creates an associated `Profile`, and creates a 6-digit OTP.
3. User verifies identity on `/verify/`.
4. Upon authentication (`/login/`), the role-dispatch middleware routes the user:
   - Applicant  -> `/applicant-dashboard/`
   - Employer   -> `/employer-dashboard/`
   - PESO Admin -> `/admin-dashboard/`

----------------------------------------------------------------------------------------------------
5.2. STAGE 2: APPLICANT PROFILE SETUP & SKILL TAXONOMY ASSESSMENT
----------------------------------------------------------------------------------------------------
1. Applicant completes the profile setup wizard (`/applicant/wizard/` or `/applicant/profile/`).
2. Enters personal background, education, work history, and target career preferences.
3. Adds competencies from the Centralized Skills Registry.
4. Rates initial proficiency level on a standardized 1-to-5 scale:
   - Level 1: Novice / Fundamental Awareness
   - Level 2: Basic / Supervised Application
   - Level 3: Intermediate / Autonomous Practitioner
   - Level 4: Advanced / Subject Matter Specialist
   - Level 5: Expert / Master Practitioner
5. Uploads resume, certifications (e.g. TESDA NC II), and supporting credentials.

----------------------------------------------------------------------------------------------------
5.3. STAGE 3: EMPLOYER VACANCY CREATION WITH SKILL MAPPING
----------------------------------------------------------------------------------------------------
1. Employer accesses Job Management (`/employer/job-management/`) and creates a new vacancy.
2. Specifies job metadata: Title, Category (IT, BPO, Engineering, Healthcare, etc.), Slots, Salary, Location.
3. Skill Mapping Requirement:
   - Employer selects 3 to 10 mandatory skills from `CentralizedSkill`.
   - Assigns a required proficiency threshold (1 to 5) for each skill.
4. System publishes the vacancy and activates the automated matching engine.

----------------------------------------------------------------------------------------------------
5.4. STAGE 4: ALGORITHMIC SKILL GAP ANALYSIS & COMPATIBILITY MATCH SCORING
----------------------------------------------------------------------------------------------------
1. The matching engine evaluates the applicant's skill inventory against vacancy requirements:
   - Match Score Calculation:
     * Full Match: Applicant proficiency >= Required proficiency (100% credit for that skill).
     * Partial Match: Applicant proficiency < Required proficiency (proportional credit).
     * Missing Skill: Skill absent from applicant profile (0% credit).
   - Weighted overall compatibility score (%) is computed and cached in `GapScoreLog`.
2. Visual Diagnostic Breakdown:
   - Green (Sufficient): Applicant meets or exceeds required proficiency level.
   - Amber (Deficiency): Applicant possesses the skill but needs higher proficiency.
   - Red (Missing): Critical skill is entirely missing from applicant profile.
3. Automated Course Mapping: Missing and deficient skills are dynamically cross-referenced with
   available `TrainingProgram` records to suggest actionable upskilling courses.

----------------------------------------------------------------------------------------------------
5.5. STAGE 5: JOB DISCOVERY, APPLICATION & HIRING PIPELINE
----------------------------------------------------------------------------------------------------
1. Discovery: Applicant browses `/applicant/job-search/` with vacancies sorted by highest compatibility.
2. Submission: Applicant clicks "Apply Now" (`/applicant/apply/<vacancy_id>/`).
   - Creates a `Referral` record in status `Pending`.
   - Notifies employer and PESO coordinators in real time.
3. Employer Evaluation:
   - Employer reviews candidate pool on `/employer/applicants/`.
   - Views applicant gap analysis (`/employer/applicant-detail/<id>/`).
4. Interview Scheduling:
   - Employer schedules an interview (`/employer/schedule-interview/`).
   - System records interview details in `Interview` model and alerts applicant.
5. Offer & Hiring:
   - Employer extends job offer via Hiring Tracker (`/employer/hiring-tracker/`).
   - Applicant reviews and accepts offer.
   - Employer marks applicant as `Hired — Probationary` or `Hired — Regular`.
   - Vacancy `remaining_slots` automatically decrements.

----------------------------------------------------------------------------------------------------
5.6. STAGE 6: PESO COORDINATOR REFERRAL & PRE-EMPLOYMENT COMPLIANCE
----------------------------------------------------------------------------------------------------
1. PESO Admin oversees the onboarding pipeline on `/peso-admin/employment-tracking/`.
2. Pre-Employment Checklist Verification:
   - Applicant uploads mandatory compliance documents:
     * NBI Clearance / Police Clearance
     * Medical Examination Certificate / Fit-to-Work
     * SSS Number / PhilHealth Number / Pag-IBIG MID / BIR TIN
     * Official Transcript / Diploma
   - PESO Coordinator audits each document and marks status as `Complete`.
3. Physical Report to Work:
   - PESO verifies candidate's actual start date at the company facility.

----------------------------------------------------------------------------------------------------
5.7. STAGE 7: TARGETED TRAINING RECOMMENDATIONS, ENROLLMENT & CERTIFICATION
----------------------------------------------------------------------------------------------------
1. If an applicant is not hired or wishes to upskill, they visit `/applicant/training/`.
2. System displays courses mapped to resolve their specific identified skill gaps.
3. Applicant self-enrolls in open courses (`/applicant/training/enroll/<id>/`).
4. Training Lifecycle Stages:
   - `Scheduled`: Open for candidate enrollment.
   - `Full / Closed`: Maximum slots filled; registration locked.
   - `In Progress`: Course active.
   - `Completed`: Course concluded.
5. Certification & Skill Upgrading:
   - PESO Coordinator accesses program roster (`/peso-admin/training-programs/<id>/`).
   - Marks graduating trainees as `Attended & Completed`.
   - System automatically upgrades the graduate's profile skill proficiency and marks source as `PESO Verified`.

----------------------------------------------------------------------------------------------------
5.8. STAGE 8: POST-PLACEMENT MONITORING & 30/60/90-DAY RETENTION AUDITING
----------------------------------------------------------------------------------------------------
1. PESO Coordinator initiates retention check-ins at 30, 60, and 90-day intervals post-hiring.
2. 30-Day Check: Initial onboarding adjustment and employer satisfaction.
3. 60-Day Check: Mid-probation performance evaluation and skill readiness confirmation.
4. 90-Day Check: Final regularization review and long-term retention status.
5. System logs outcomes (`Regularly Employed`, `Probation Extended`, `Separated`).
6. Exportable DOLE/LGU compliance reporting generated via `/peso-admin/analytics/export/`.
